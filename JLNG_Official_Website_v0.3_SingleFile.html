01 / THE IDEA

Not just a bridge.
A language of its own.

JLNG is being built as an independent programming language, not merely a wrapper around existing tools. Its own syntax and language model form the foundation.

Interoperability adds another dimension: the ability to bring different language ecosystems into one project, so developers can work with the tools they know best.

ONE LANGUAGE. OPEN CONNECTIONS.
02 / WHAT MAKES JLNG

Built around possibility.

Three ideas shape the direction of the project. Each is being developed step by step.

01⌘

Native Language

JLNG has its own syntax, semantics, and language design. The goal is to make JLNG useful as a standalone language.

ITS OWN IDENTITY
02⇄

Connect JLNG with external languages such as Python, JavaScript, and C — bringing different strengths into one workflow.

03 / THE ROAD AHEAD

A long-term vision.

JLNG is a growing project. The roadmap is a direction, not a promise of release dates.

V1.0.0 CURRENT FOCUS

Foundation

Stabilize the core language, compiler, interoperability, and developer experience.

V2–V3

Grow the language

Expand language capabilities, libraries, tooling, and the wider developer ecosystem.

V4

Self-hosting

Work toward a compiler written in JLNG that can build itself through a verified bootstrap process.

V5+

AI-assisted evolution

Explore JLNG-native AI tooling that can analyze, propose, test, and help improve the compiler under controlled review.
